# 安全评估结果查看系统

一个动态的Web界面，用于查看安全评估结果。

## 功能特性

### 1. 实时解析和动态显示
- **实时解析**：服务器启动时会实时扫描 `eval_results/` 目录中的评估结果文件
- **动态显示**：无需手动更新 `results.json` 文件，刷新浏览器即可看到最新结果
- **自动识别**：支持PR评估（`pr_仓库名_PR号.json`）和仓库评估（`repo_仓库名.json`）两种文件格式

### 2. 筛选和搜索功能
- **按类型筛选**：区分PR评估和仓库评估
- **按仓库筛选**：根据仓库名称筛选结果
- **搜索功能**：支持搜索仓库名称或PR号
- **快速筛选**：使用关键词快速定位评估结果

### 3. 结果展示
- **卡片视图**：简洁的卡片布局展示评估结果
- **详细信息**：点击"查看详情"显示完整的评估报告
- **安全发现**：显示安全漏洞和问题的详细描述
- **严重程度标记**：
  - 🔴 高危（HIGH）
  - 🟡 中危（MEDIUM）
  - 🟢 低危（LOW）

### 4. 用户体验
- **响应式设计**：支持桌面、平板和手机等多种屏幕尺寸
- **加载状态**：显示加载动画和错误信息
- **交互反馈**：卡片悬停效果和按钮点击反馈
- **平滑滚动**：详情页面平滑过渡

### 5. 技术特点
- **无外部依赖**：使用Node.js内置模块，无需额外安装依赖
- **轻量级**：服务器和客户端代码都非常精简
- **高性能**：快速解析和响应请求
- **可扩展性**：代码结构清晰，便于后续功能扩展

## 使用方法

### 1. 启动服务器

```bash
cd web
node server.js
```

服务器将运行在 `http://localhost:8081`

### 2. 访问Web界面

在浏览器中打开 `http://localhost:8081`

### 3. 查看评估结果

- 服务器会自动读取 `../eval_results/` 目录中的所有评估结果
- 支持的文件名格式：
  - PR评估：`pr_仓库名_PR号.json`（如：`pr_anthropics_claude-code-security-review_70.json`）
  - 仓库评估：`repo_仓库名.json`（如：`repo_wang-junjian_LingMaster.json`）

### 4. 停止服务器

按 `Ctrl+C` 停止服务器

## 技术说明

- **服务器**：Node.js内置HTTP服务器
- **API**：提供 `/api/results` 端点返回JSON格式的评估结果
- **前端**：HTML5 + CSS3 + JavaScript（ES6+）
- **依赖**：无外部依赖（使用Node.js内置模块）
